부탁 한 번의 흐름

말로 맡기면, 끝까지 해요

Kelo는 찾고, 확인받고, 마무리하고, 그날 일을 돌아봐요. 휴대폰에서 하나하나 보여요.

  1. 01

    말이나 글로 맡겨요

    글이나 말로 부탁하세요. 사진과 PDF, Word, Excel 문서도 함께 보낼 수 있어요. Kelo는 내가 쓴 언어로 답해요.

  2. 02

    자기 브라우저로 찾아요

    Kelo 서버 안의 전용 Chromium으로 사이트를 열고, 비교하고, 양식을 채워요. 휴대폰에서 실시간으로 보다가 직접 조작하고 다시 맡길 수 있어요. 이 브라우저는 집 안 네트워크에 닿지 못하게 막혀 있어요.

  3. 03

    확정하기 전에 물어요

    결제, 주문, 예약, 보내기, 삭제처럼 되돌리기 어려운 일은 휴대폰에 허락 카드가 먼저 와요. 무엇을 하려는지 말로 보여 주고, 허락해야 진행해요.

  4. 04

    밤마다 돌아보고 배워요

    하루가 끝나면 대화를 돌아보고 내 취향을 짧은 규칙으로 제안해요. 남길지 버릴지는 내가 정하고, 버린 규칙은 다시 제안하지 않아요.

정해 둔 때에 알아서

“매일 아침 9시쯤”, “30분마다”처럼 말해 두면 그때 해요. 페이지에 어떤 글자가 뜨거나 가격이 기준 아래로 내려가면 그때만 깨어나고, 확인에는 AI 모델을 쓰지 않아요.

키체인

비밀번호는 채팅으로 받지 않아요

비밀번호와 API 키는 앱의 입력 칸으로만 받아 Kelo 서버에 잠가 둬요. 저장한 값은 아무도 읽을 수 없고, 비서도 값을 보지 않고 써요.

결제 카드

허락한 결제만 해요

카드마다 자동 결제를 켤지 정해요. 끈 카드는 휴대폰만 아는 키로 잠겨 서버도 읽지 못하고, 결제마다 지문이나 얼굴로 허락해요.

다짐

다짐을 계획으로 나눠요

목표를 적어 두면 내가 할 일과 Kelo가 할 일로 나누고, 숫자와 기한을 함께 챙겨요.

여러 사람이 쓰는 방법

서버 하나에 한 사람, 휴대폰은 몇 대든

Kelo 서버 하나는 한 사람의 비서예요. 함께 쓰려면 사람마다 서버를 하나씩 두면 돼요.

  • 한 사람에 서버 하나

    대화, 기억, 키, 카드가 사람마다 완전히 나뉘어요. 서로의 대화는 보이지 않아요.

  • 휴대폰은 몇 대든

    서버 하나에 휴대폰과 데스크톱 앱을 몇 대든 연결해요. QR 코드 한 번이면 돼요.

  • 컴퓨터 한 대에 여러 벌

    서버를 설치한 컴퓨터 한 대에 Kelo를 여러 벌 띄울 수 있어요. 벌마다 주소와 데이터가 따로예요.

  • 자원은 숫자로 정해요

    벌마다 쓸 RAM, CPU, 디스크를 정하거나, 컴퓨터가 가진 만큼 쓰게 둘 수 있어요.

개인정보

당신의 정보는 당신의 서버에만 있어요

대화, 메모, 저장한 키와 카드는 모두 당신이 운영하는 Kelo 서버에 저장돼요. 개발자에게는 그 서버에 들어갈 방법이 없고, 당신의 대화를 따로 받아 보관하지도 않아요.

대화는 당신이 고른 AI 서비스(예: Anthropic, Google)로 보내져 답을 받아요. 소스 코드가 공개되어 있어서 누구나 직접 확인할 수 있어요.

Kelo를 위한 Oracle Cloud Always Free

Oracle Cloud의 Always Free에는 계속 무료인 Arm 서버(2 OCPU · 메모리 12 GB)가 들어 있고, Kelo를 돌리기에 충분해요. 여기에 Kelo를 설치하고 Kelo 주소(현재 한정 제공)로 연결하세요. 옆에 FreeLLMAPI를 함께 띄우면 여러 AI 회사의 무료 사용량을 OpenAI 호환 주소 하나로 쓸 수 있어요. 그 주소는 앱의 마이 → 모델 → Custom endpoint에 넣어요.

  • 7일 동안 거의 쓰지 않은 무료 서버(CPU, 네트워크, 메모리 모두 20% 미만)는 Oracle이 회수할 수 있어요. 계정을 Pay As You Go로 업그레이드해도 Always Free 자원은 계속 무료이고, 업그레이드하면 회수되지 않는다는 경험담이 많아요.
  • 무료 모델은 유료 모델보다 느리고, 도구를 쓰는 일이 덜 안정적이에요.
  • Oracle, FreeLLMAPI, 각 AI 회사의 약관이 그대로 적용돼요.

자주 묻는 질문

궁금한 점

더 자세한 건 설치 안내에 있어요.

어떤 컴퓨터가 필요해요?

Docker가 돌아가는 Mac, Linux, Windows 컴퓨터면 돼요. 최소 RAM 2GB · CPU 2코어 · 남은 디스크 10GB, 권장은 RAM 4GB · CPU 4코어 · 남은 디스크 20GB예요.

AI 모델 비용은 어떻게 내요?

내가 고른 AI 회사에 내 API 키로 직접 내요. Kelo가 중간에서 받지 않아요. 로컬 모델을 쓰면 따로 낼 비용이 없어요.

서버를 설치한 컴퓨터를 끄면 어떻게 돼요?

비서도 함께 쉬어요. 다시 켜면 두 시간 안에 놓친 예약 실행은 한 번 따라잡고, 그보다 오래된 건 다음 시간으로 넘겨요.

휴대폰 연결 링크를 눌렀더니 이 페이지가 열렸어요.

Kelo 앱을 열고 연결 화면에서 QR 코드를 스캔하거나, 받은 링크를 ‘링크 붙여넣기’에 그대로 붙여 넣으세요. 링크는 10분 동안 한 번만 쓸 수 있어요.

내 대화가 Kelo 개발자에게 가나요?

아니요. 대화는 Kelo 서버와 답을 만드는 AI 회사 사이에서만 오가요. 앱에서 답을 길게 눌러 ‘신고하기’로 직접 보낸 답만 개발자에게 가요.

가족이 함께 쓸 수 있어요?

네. 서버를 설치한 컴퓨터 한 대에 사람마다 Kelo를 한 벌씩 띄우면, 대화와 키가 완전히 나뉘어요.

iPhone에서도 쓸 수 있어요?

iPhone 앱은 만들고 있어요. 지금은 Android, Windows, macOS 앱이 먼저예요.

어떤 언어로 쓸 수 있어요?

앱과 서버 안내 모두 한국어, 영어를 비롯한 20개 언어로 나와요.

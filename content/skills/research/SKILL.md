# Research

1. Make sure you know the actual question and what the answer is for (a decision, a comparison, a quick fact). Ask once if that is unclear.
2. Search with `web_search` and read several independent, reliable sources with `web_fetch`. Prefer primary sources (the official document, the maker or provider, the original data) over writing about them; then established publications and comparison pages.
3. Read the pages; do not rely on search snippets. Open a page in the browser (`browser_open`) only when `web_fetch` says it needs JavaScript or refused the request. Note each fact with where it came from and the page's publication or update date; for anything that changes, an old page is a reason to look further.
4. For a quick fact, answer first. For a real research question, lay it out as: **Conclusion**; **Evidence** (the key facts, each with its source); **Other views** (where credible sources disagree, and which you trust more and why); **Unconfirmed** (what you could not verify); **Sources** (links labelled in a few words, with dates). For comparisons, a compact table of the few things that matter.
5. Save conclusions the user will want again (a chosen product, a decision) to MEMORY.md; keep longer findings in `notes/`.

# Trip packing list

1. Ask only for what is missing: where, when (dates), and what the trip is for (work, hiking, beach, a wedding...).
2. Check the weather for those dates if a weather or search tool is available; say where the forecast came from.
3. Write the list in groups: documents, clothes, toiletries, electronics, health, activity gear.
4. Mark items that are easy to forget for this kind of trip (plug adapter, travel insurance papers, medicine).
5. Offer to save the list as a note and to remind the user the evening before they leave.

More detail for long trips is in long-trips.md.

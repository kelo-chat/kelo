# Code of Conduct

Kelo adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback, and do not harass,
insult or demean anyone. It applies in all project spaces (issues, pull requests, discussions, and any other Kelo
channel) and when someone represents the project in public.

## Reporting

Report unacceptable behaviour to **support@kelo.chat**. All reports are reviewed and handled confidentially. The project
maintainers enforce the code of conduct using the enforcement guidelines of the Contributor Covenant 2.1 (correction,
warning, temporary ban, permanent ban).

직접 설치해 쓰는 나만의 AI 비서

Kelo는 직접 설치한 서버에서 돌아가며 자기 브라우저와 연결한 서비스로 심부름을 해요. 결제나 전송, 삭제 전에는 휴대폰으로 꼭 먼저 물어봐요.

서버 설치하기 앱 받기

Kelo는 진짜 브라우저로 심부름해요

Kelo는 서버 안의 전용 Chromium으로 사이트를 열고, 찾고, 입력해요. 휴대폰에서 실시간으로 보다가 넘겨받고, 다시 돌려줄 수 있어요.

  • 집 안 네트워크에는 닿지 못하게 막혀 있어요
  • 비밀번호와 카드 번호는 기록에 남지 않아요
  • 사거나 보내기 전에 승인 카드가 먼저 와요
먼저 묻는 일 보기

Kelo는 돈이 나가기 전에 꼭 물어요. 카드와 키는 잠가 둬요.

Kelo는 허락한 결제만 해요

카드는 휴대폰만 아는 키로 잠겨요. 한도를 정하지 않았다면 결제마다 지문이나 얼굴로 허락해요.

Kelo는 비밀번호를 채팅으로 받지 않아요

비밀번호와 API 키는 채팅이 아니라 입력 칸으로만 받아요. 비서는 값을 보지 않고 써요.

Kelo는 밤마다 내 취향을 배워요

하루를 돌아보고 짧은 규칙을 제안해요. 남길지 버릴지는 내가 정해요.

내 서버, 내 데이터

대화, 기억, 파일, 키는 직접 설치한 Kelo 서버에 남아요. Kelo를 만든 쪽 서버에는 쌓이지 않아요.

정해 둔 때에 Kelo가 하는 일

“매일 아침 9시쯤”, “30분마다”처럼 말해 두면 그때 알아서 해요. 오래 걸리는 일은 따로 돌리고, 채팅은 계속 쓸 수 있어요.

  • 예약 실행한 번, 매일, 몇 분마다
  • 지켜보기가격이 내려가면 깨워요. AI 모델은 안 써요
  • 백그라운드 작업채팅하는 동안 자료 조사와 표 만들기
  • 다시 알림멈춘 일은 최대 두 번까지 알려 줘요

Kelo는 다짐을 단계로 나눠요. 내가 할 일과 Kelo가 할 일로요.

직접 돌리는 다른 앱과도 이어져요

집에서 쓰는 앱을 네트워크나 Tailscale의 주소(예: http://192.168.0.10:8123)로 Kelo에 연결해요. Kelo가 그 앱에 직접 물어보니 우리 서버를 거치지 않고, 아무것도 네트워크 밖으로 나가지 않아요.

Home Assistant, Frigate, Immich, Paperless-ngx, Mealie, Tandoor, Grocy, Actual Budget, Firefly III, Linkwarden, Karakeep, Wallabag, Miniflux, FreshRSS, n8n, Uptime Kuma, Beszel, AdGuard Home, Pi-hole, Nextcloud, Gitea, Forgejo.

“현관문 열어 줘”, “보일러 꺼 줘”처럼 직접 말하면 Kelo가 바로 해요. Kelo가 스스로 하려는 일이나 웹페이지·메일·메시지의 글에서 비롯된 요청은 먼저 물어봐요.

Kelo는 자기 자신이나 클라우드 서버의 관리 정보에는 연결하지 않아요. Kelo 서버 자신을 가리키는 주소(127.0.0.1)와 클라우드 메타데이터 주소(169.254.x.x)는 거절해요. 추후 예정: 자체 서명 인증서를 쓰는 https 주소 (예: Frigate의 로그인 포트 8971).

무료 클라우드 서버에 Kelo 올리기

팁 · 무료로 운영하기

Kelo를 위한 Oracle Cloud Always Free

Oracle Cloud의 Always Free에는 계속 무료인 Arm 서버(2 OCPU · 메모리 12 GB)가 들어 있고, Kelo를 돌리기에 충분해요. 여기에 Kelo를 설치하고 Kelo 주소(현재 한정 제공)로 연결하세요. 옆에 FreeLLMAPI를 함께 띄우면 여러 AI 회사의 무료 사용량을 OpenAI 호환 주소 하나로 쓸 수 있어요. 그 주소는 앱의 마이 → 모델 → Custom endpoint에 넣어요.

  • 7일 동안 거의 쓰지 않은 무료 서버(CPU, 네트워크, 메모리 모두 20% 미만)는 Oracle이 회수할 수 있어요. 계정을 Pay As You Go로 업그레이드해도 Always Free 자원은 계속 무료이고, 업그레이드하면 회수되지 않는다는 경험담이 많아요.
  • 무료 모델은 유료 모델보다 느리고, 도구를 쓰는 일이 덜 안정적이에요.
  • Oracle, FreeLLMAPI, 각 AI 회사의 약관이 그대로 적용돼요.

자주 묻는 질문

더 자세한 건 설치 안내에 있어요.

{{svg:thinking}}

  • Kelo에는 어떤 컴퓨터가 필요해요?

    Docker가 돌아가는 Mac, Linux, Windows 컴퓨터면 돼요. 최소 RAM 2GB · CPU 2코어 · 남은 디스크 10GB예요.

  • Kelo의 AI 모델 비용은 어떻게 내요?

    내가 고른 AI 회사에 내 API 키로 직접 내요. Kelo가 중간에서 받지 않아요.

  • Kelo 서버가 꺼지면 어떻게 돼요?

    비서도 함께 쉬어요. 다시 켜면 두 시간 안에 놓친 예약 실행을 한 번 따라잡아요.

  • Kelo 연결 링크를 눌렀더니 이 페이지가 열렸어요.

    Kelo 앱을 열고 QR 코드를 스캔하거나, 링크를 ‘링크 붙여넣기’에 붙여 넣으세요. 10분 동안 한 번만 쓸 수 있어요.

  • 내 대화가 Kelo 쪽으로 가나요?

    아니요. 대화는 내 Kelo 서버와 답을 쓰는 AI 회사 사이에서만 오가요.

  • iPhone에서도 Kelo를 쓸 수 있어요?

    네. iPhone 앱은 App Store에서 받을 수 있어요(iOS 17 이상).

  • Kelo는 어떤 언어로 쓸 수 있어요?

    앱과 서버 안내 모두 한국어, 영어를 비롯한 20개 언어로 나와요.
